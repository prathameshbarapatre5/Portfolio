# Portfolio2 - Monochrome Space Theme

A minimalist black & white portfolio with glassmorphism effects for a Robotics Engineer.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development
npm run dev

# Build for production
npm run build
```

## 📁 Structure
- **Home**: Two-column layout with photo
- **About**: Biography, skills, experience, education
- **Projects**: Bento grid with 6 projects
- **Publications**: 6 papers + 2 talks
- **Articles**: 3 podcasts + 4 magazines

## 🎨 Theme
- Pure black & white monochrome
- Glassmorphism effects
- Subtle white glows
- Minimalist aesthetic

## 🌐 Deploy
Automatically deploys to GitHub Pages on push to main branch.

Built with Next.js 14 + TypeScript + Tailwind CSS
