# Futuristic Robotics Portfolio

A stunning dark-themed portfolio with glassmorphism effects and neon accents, built with Next.js 14.

## 🎨 Design Features
- **Dark Theme**: Deep zinc-950 background
- **Glassmorphism**: Frosted glass effects throughout
- **Neon Accents**: Purple, cyan, and pink gradients
- **Animations**: Floating orbs, gradient text, smooth transitions
- **Typography**: Inter font family

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 📁 Pages
- **Home**: Hero with gradient text + infinite skills marquee
- **About**: Biography + skills + experience + education
- **Projects**: Bento grid layout with 6 projects
- **Publications**: 6 research papers + 2 YouTube talks
- **Articles**: 3 Spotify podcasts + 4 CosmicWeb magazines

## 🌐 Deployment

### First Time Setup:
```bash
# 1. Install dependencies (creates package-lock.json)
npm install

# 2. Commit everything
git add .
git commit -m "Initial commit with lock file"

# 3. Push to GitHub
git push origin main
```

### GitHub will automatically:
- Build your site via GitHub Actions
- Deploy to GitHub Pages
- Make it live at: `https://prathameshbarapatre5.github.io/Portfolio2/`
