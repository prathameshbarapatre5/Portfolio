# 🎨 COLOR SCHEME UPDATE

## Changes Made

Updated entire website to use **only Purple and Blue** gradients (removed cyan and pink).

## New Color Palette

### Primary Colors:
- **Purple**: `#a855f7` (primary)
- **Blue**: `#6366f1` (accent - indigo blue)
